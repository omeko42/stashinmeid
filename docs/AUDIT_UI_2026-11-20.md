Tanggal: 2026-11-20
Scope: baca-saja. Belum ada kode yang diubah.

## Ringkasan

Keluhan user: tampilan "garing". Penyebabnya bukan satu hal, tapi tumpukan:

1. Tipografi tidak pernah kepakai (font Geist dimuat, CSS memaksa Arial).
2. Semua kartu memakai pola yang sama (`rounded-3xl bg-zinc-900/70 border-white/10`) sehingga hierarki datar.
3. Angka statis, chart default, tidak ada micro-interaction, tidak ada empty state yang mengajak.
4. Nol aksesibilitas: 1 `aria-label` di 2.253 baris, tanpa `focus-visible`, tanpa `prefers-reduced-motion`.
